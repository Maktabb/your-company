# بوابة العملاء — مكتب محمود سالم

واجهة متابعة ملفات العملاء: محادثة مع الفريق، خطوات الملف، بيانات الشركة، والمستندات.

- الواجهة مستضافة على GitHub Pages.
- البيانات والمستندات محفوظة في Google Sheets و Google Drive الخاصين بالمكتب، ولا تُرفع إلى GitHub.
- الربط بالخادم يتم من ملف `config.js`.

لا تضعوا ملف `Code.gs` في هذا المستودع.
